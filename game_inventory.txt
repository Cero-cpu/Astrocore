3. DETAILED FILE AND SCRIPT SCHEMATICS
--------------------------------------------------------------------------------

=======================================
[ lobby.gd // lobby.tscn ]
=======================================
* Root Node: Node2D
* Purpose: Provides an elite pilot terminal (Lobby) featuring star parallax, ship rotation/floating tweens, ship skin swapping, and starting buttons.
* Key Variables:
  - `scroll_speed`: Float (Background vertical scroll rate, 50.0).
  - `scroll_offset`: Float (Tracks parallax scroll value).
  - `touch_active` / `touch_dragging` / `touch_start_pos`: Vector2/Bool (Touch swipe drag variables).
* Key Methods:
  - `_ready()`: Ensures tree is unpaused. Restores last-chosen player skin. Connects global `MusicManager.play_lobby_music()`.
  - `_process(delta)`: Scrolls stars/stars_far and floats the ship preview vertically via sin wave.
  - `_setup_lobby_ui()`: Creates and styles a centered dynamic terminal layout. Features Title (ASTROCORE), Subtitle, and skin GridContainer.
    * Touch scrolling bypass: Intercepts `gui_input` of buttons and `ScrollContainer` using global coordinates (`event.global_position`) to allow seamless mobile swipe-scrolling over the buttons while keeping tapping responsive.
  - `_select_skin(path, button)`: Connects button trigger to temporary loading, setting the ship's skin, and playing bounce tween feedback.

=======================================
[ player.gd // player.tscn ]
=======================================
* Root Node: Area2D (Collision Layer: 1 | Collision Mask: 12)
* Purpose: Handles the user's ship movement, weapon styles, fire rates, upgrades, invincibility, and skins.
* Key Variables:
  - `speed`: Float (400.0)
  - `health`: Int (100)
  - `max_health`: Int (100)
  - `fire_rate`: Float (0.5 base)
  - `evolution_level`: Int (1 to 5, scales size and projectile bursts)
  - `current_style`: WeaponStyle enum (Tracks current powerup weapon style)
  - `selected_skin_path`: Static String (Saves selected ship across lobby/game)
  - `projectile_color`: Color (Unique HDR color matched to chosen skin)
* Key Methods:
  - `_ready()`: Softens continuous laser sounds to `-14.0` dB to keep a discrete mechanical tick.
  - `_process(delta)`: Lerp-follows mouse or touch drag inputs. Tilts ship rotation based on horizontal direction.
  - `set_skin(scene_path)`: Loads skin scene, duplicates its `SpriteFrames` into Player's `AnimatedSprite2D`, maps neon bullet colors, and removes recolor shader for custom skins.
  - `shoot()`: Contains 18 match weapon cases that spawn projectiles with custom patterns.
  - `_play_sfx(stream, volume_db)`: Route audio clips directly to the `"SFX"` bus for master volume control.
  - `take_damage(amount)`: Activates invincibility, flashes screen red, shakes screen, triggers hit-stop, and plays damage sfx at `-5.0` dB.

=======================================
[ projectile.gd // projectile.tscn ]
=======================================
* Root Node: Area2D (Collision Layer: 2 | Collision Mask: 4)
* Purpose: Configures and drives player bullets with complex patterns like spirals, waves, orbits, and cleans them when out of screen.
* Key Variables:
  - `speed`: Float (600.0)
  - `direction`: Vector2 (UP default)
  - `skin_color`: Color (Sentinel: -1 means random pink/cyan, else matches skin)
* Key Methods:
  - `_process(delta)`:
    * "wave_projectiles": Oscillates position.x via sin(time * 10.0) * 10.0 (supports wave_flip).
    * "snake_projectiles": Oscillates position.x via cos(time * 20.0) * 20.0.
    * "orbit_projectiles": Moves in circular orbit around player offset by rotated angle.
    * General: Moves lineally along `direction` * `speed`.
  - `_on_area_entered(area)`: Triggers `take_damage(1)` if area is in "enemies" group, then frees itself.

=======================================
[ enemy.gd // enemy.tscn ]
=======================================
* Root Node: Area2D (Collision Layer: 4 | Collision Mask: 3)
* Purpose: Defines dynamic normal enemies (spaceships and asteroids). Fixes size-matching between visual textures and physical hitboxes.
* Key Variables:
  - `health`: Int (1 + game_time/60.0, scales over time)
  - `speed`: Float (Scales over time with game_time * 2.0)
  - `original_sprite_scale`: Vector2 (Stored in _ready, prevents hit shrinking bugs)
  - `is_asteroid`: Bool (Asteroids tumble, lack shooters, scale whole body)
* Key Methods:
  - `_ready()`: Loads 1 of 17 textures dynamically.
    * Dynamically configures `CollisionShape2D.shape` (a `RectangleShape2D`) matching texture size * `original_sprite_scale` + `Vector2(8, 8)` generous padding for satisfying combat feel.
    * Clamp horizontal position dynamically using texture scale and a `12.0` px safety buffer, ensuring that no wing or rotating corner ever gets cut off by screen boundaries.
  - `take_damage(amount)`:
    * Hits: SFX enrouted to `"SFX"` at `-15.0` dB, pure white HDR flash, and a scale-pop.
    * Death: Triggers explosion, screen shake, and bouncy floating combo score popups. Enroutes normal explosion deaths to `"SFX"` at `-10.0` dB.

=======================================
[ game.gd // game.tscn ]
=======================================
* Root Node: Node2D
* Purpose: Central gameplay supervisor. Manages score, game levels, 10 backdrops, combos, boss triggers, powerup spawns, vignette HP alerts, and pauses.
* Key Variables:
  - `score`: Int
  - `game_level`: Int
  - `total_kills`: Int (spawns a boss every 50 kills)
  - `boss_active`: Bool (disables spawns, spawns continuous boss items)
  - `themes`: Array (10 curated cosmos themes using dynamic layered backdrops)
* Key Methods:
  - `_ready()`: Triggers `MusicManager.play_game_music()`. Sets up seamless repeating scroll region. Removes the blurry cyan `HUDFrame` glow and disables grid backdrops to ensure perfect map clarity.
  - `_process(delta)`: Synchronizes scrolling parallax layers: `$BackgroundTex` (always fully opaque, solid backdrop) and `$Stars` (independent transparent scrolling nebula overlay), preventing any gray engine viewport gaps.
  - `on_enemy_killed()`: Increments combo, awards score, rolls for item drops, and triggers Boss. Resolves division warnings using modulo math (`total_kills - (total_kills % KILLS_PER_BOSS)`).
  - `spawn_boss(scene)`: Triggers warning labels and chromatic aberration, then spawns Boss or Boss2.
  - `on_boss_killed()`: Triggers slow-mo, screen flash, and spawns powerups.
  - `upgrade_player()`: Increases `game_level`, transitions the background theme color & texture via synchronized parallel tweens.
  - `setup_ui()`: Renders progress bar, health bars, pause screens, retry/lobby menus. Updates time formatting with float literals to prevent warnings.

5. CRITICAL DESIGN RULES & AI DIRECTIVES
--------------------------------------------------------------------------------
- RULE 1: NEVER HARDCODE sprite scale updates in hit animations. Always use `original_sprite_scale` to prevent shrinking bugs.
- RULE 2: Keep enemy and boss collision shapes generous (`visual_size + padding`). Keep player hitboxes small and tight.
- RULE 3: Do not remove any of the 18 WeaponStyle cases inside `player.gd` or `powerup.gd`.
- RULE 4: Ensure dynamic screen scaling remains intact. Viewport size is `720x1280` in expand mode, and all background assets must scale centered by 1.5x width/height to accommodate safe areas.
- RULE 5: Keep HDR glow modulations active. Modulation values are high (e.g. Color(5, 0.2, 1.5)) to feed the engine's glow shaders.
- RULE 6: Balance auditory mixes strictly: continuous lasers at `-14.0` dB, enemy hits at `-15.0` dB, powerups at `-6.0` dB, and enroute all sound effects to the `"SFX"` bus and music tracks to the `"Music"` bus.
- RULE 7: Mobile scrolling containers must use global coordinates (`event.global_position`) and bypass button swallowing via custom drag threshold checks to ensure buttery smooth swiping.
- RULE 8: Scrolling backdrops must use fully opaque textures at the bottom (`BackgroundTex`), and transparent elements (nebulae, clouds, stars) as independent overlay layers to eliminate grey engine gaps.
